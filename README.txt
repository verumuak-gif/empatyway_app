# EmpatyWay

Proyecto Flutter reconstruido a partir de la guía proporcionada.

## Para generar el APK

1. Instalar Flutter.
2. Abrir una terminal dentro de esta carpeta.
3. Ejecutar:

flutter pub get

4. Generar el APK:

flutter build apk --release

El archivo resultante estará en:

build/app/outputs/flutter-apk/app-release.apk

## Nota

La guía original utiliza Google Maps, por lo que una configuración real de Google Maps/API Key puede ser necesaria para mostrar el mapa en Android.
